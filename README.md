# HIY CLIENTS (Railway-ready)

## Local run
1) Install deps
- npm install

2) Start
- npm start

Open: http://localhost:3000

## Environment variables (recommended)
- NODE_ENV=production
- SESSION_SECRET=long-random-string
- ADMIN_USER=admin
- ADMIN_PASS=your-strong-pass
- CLIENT_USER=desijayka
- CLIENT_PASS=your-client-pass
- CLIENT_ID=c1
